# Интерактивный тренажёр по морфологии

**Подзаголовок:** «Изучай части речи на своём уровне»

## Назначение ресурса

Сайт предназначен для изучения четырёх частей речи: имени существительного, имени прилагательного, глагола и местоимения. Материал построен так, чтобы ученик не только видел правило, но и применял его с опорой на инфографику и интерактивные задания.

Ресурс разработан в рамках дипломного проекта **«Методические приёмы использования инфографики на уроках русского языка в казахской школе»**.

## Три уровня обучения

| Уровень | Для кого | Основная учебная задача |
| --- | --- | --- |
| Начинающий | 3–4 класс | Узнавать и различать части речи на простых примерах |
| Исследователь | 5–6 класс | Понимать правило и применять его в словосочетаниях и предложениях |
| Эксперт | Продвинутый уровень | Анализировать языковой материал, редактировать текст и объяснять решение |

На каждом уровне доступны четыре темы и по три работающих задания в каждой теме. Всего в проекте предусмотрено **36 интерактивных заданий**.

## Технологии

- HTML5;
- CSS3, включая адаптивную сетку и визуальные инфографические блоки;
- чистый JavaScript без библиотек и сборки;
- `localStorage` для хранения выбора уровня и выполненных заданий;
- SVG-иллюстрации и локальные изображения.

Проект не требует Node.js, npm, базы данных или сервера.

## Как открыть сайт локально

1. Распакуйте ZIP-архив.
2. Откройте файл `index.html` двойным щелчком в браузере.
3. Выберите уровень и выполните задания.

Все основные функции работают непосредственно из файла `index.html`: переходы построены на hash-навигации, поэтому страницы не требуют серверной маршрутизации.

## Как заменить старую версию на GitHub Pages

### Вариант через интерфейс GitHub

1. Откройте репозиторий, в котором опубликована старая версия сайта.
2. На всякий случай скачайте старую версию как резервную копию.
3. Удалите старые файлы сайта из ветки публикации или замените их содержимым этого проекта.
4. Загрузите **содержимое папки проекта**, а не саму внешнюю папку: файл `index.html` должен находиться в корне репозитория или выбранной папки публикации.
5. Откройте `Settings` → `Pages`.
6. В разделе `Build and deployment` выберите `Deploy from a branch`.
7. Выберите ветку `main` и папку `/(root)`, затем сохраните настройки.
8. После публикации откройте адрес GitHub Pages и проверьте стартовый экран, темы и сохранение прогресса.

### Вариант через Git

```bash
git clone <адрес-вашего-репозитория>
cd <папка-репозитория>
# удалите старые файлы сайта и скопируйте сюда содержимое нового проекта
git add .
git commit -m "Обновить интерактивный тренажёр по морфологии"
git push origin main
```

## Как сохраняется прогресс

После правильного выполнения задания его идентификатор записывается в `localStorage` браузера. Сохраняются:

- последний выбранный уровень;
- выполненные задания по каждой теме;
- вычисляемый процент темы и всего уровня.

Прогресс хранится только на текущем устройстве и в текущем браузере. Кнопка **«Сбросить прогресс»** на странице результатов удаляет достижения выбранного уровня после подтверждения.

## Сохранённые материалы старой версии

Четыре исходные инфографические схемы сохранены и подключены как дополнительные памятки на уровне «Эксперт»:

- `legacy-noun.png`;
- `legacy-adjective.png`;
- `legacy-verb.png`;
- `legacy-pronoun.png`.

В папке `original-assets/` также оставлены прежняя иконка, локальный видеоматериал и основные исходные файлы старой версии для архивной справки. В новой логике обучения они не заменяют адаптивные HTML/CSS-инфографики.
